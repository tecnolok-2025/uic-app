# UIC App v0.36.5

## Cambios principales

- Se reemplaza el botón inferior **Pro.Industrial** por **Trazabilidad**.
- El acceso a **Trazabilidad** queda disponible únicamente con clave de administrador.
- Se incorpora registro persistente de uso de la app: visitas, pantallas, botones, IP técnica, sesión técnica, navegador/dispositivo y últimos movimientos.
- Se agrega tablero gráfico de trazabilidad con KPIs, botones más visitados, pantallas más consultadas, visitas por día, histórico por IP y crecimiento de almacenamiento.
- Se integra el consumo de trazabilidad al semáforo/medición de almacenamiento persistente.
- Se mejora la estética de los botones de accesos rápidos con mayor contraste, borde, relieve y legibilidad, manteniendo el diseño general.
- Se actualiza versión PWA/API, cacheId y start_url a **0.36.5**.

## Validaciones sugeridas

1. Subir backend y frontend.
2. Abrir la app en web, iPhone y Android.
3. Verificar que el botón inferior diga **Trazabilidad**.
4. Confirmar que sin clave admin no permite ingresar al tablero.
5. Ingresar con clave admin y verificar los gráficos.
6. Navegar por varios botones y actualizar el tablero para observar los registros.
