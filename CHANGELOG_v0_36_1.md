# CHANGELOG — v0.36.1

## Cambios
- Se elimina la solicitud de clave para el botón **Requerimientos institucionales**.
- El botón ahora abre directamente el sistema externo: `https://cpf-web.onrender.com/`.
- Se retira de la interfaz el modal de ingreso de clave asociado a Requerimientos institucionales.
- Se actualiza el texto del Manual para reflejar que Requerimientos institucionales es un acceso directo externo.
- Se actualiza la versión PWA/API a 0.36.1.
- Se actualiza `cacheId`, `id` y `start_url` PWA para favorecer actualización en web, iPhone y Android.

## Validación sugerida
- Verificar que en Inicio el botón **Requerimientos institucionales** abra el enlace directamente sin pedir clave.
- Verificar que en Ajustes la versión visible sea 0.36.1.
